# Hello World React 19 App

A simple Hello World application built with React 19 and Vite.

## Features

- Built with React 19.1.1
- Bundled with Vite 7
- Deployed on GitHub Pages
- Modern gradient styling

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

This app is automatically deployed to GitHub Pages using GitHub Actions when changes are pushed to the default branch.

View the live app at: https://parthjeet.com/
